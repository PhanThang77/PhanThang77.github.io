Hướng dẫn sử dụng
PDF Compare Pro

Làm theo các bước dưới đây để kích hoạt và sử dụng phần mềm sau khi tải về.

1

Chạy thử lần đầu (lấy Machine ID)

  1. Giải nén file đã tải về (nếu là file .zip).
  2. Bấm đúp vào PDF_Compare_Pro.exe để chạy.
  3. Trình duyệt sẽ tự mở sau 1-2 giây — nếu không tự mở, vào trình duyệt gõ http://localhost:8000.
  4. Màn hình sẽ hiện dòng "Activation required" kèm Machine ID — mã riêng của máy bạn.

Máy chưa có license.dat sẽ luôn báo dòng này — đây là điều bình thường, chưa phải lỗi.

2

Gửi Machine ID cho chúng tôi

Chụp màn hình hoặc copy nguyên văn dòng Machine ID, gửi qua email phanthangjp@gmail.com khi đăng ký mua.

3

Nhận file license.dat

Sau khi xác nhận thanh toán, bạn sẽ nhận lại 1 file tên license.dat — đây là "chìa khóa" kích hoạt riêng cho đúng máy bạn, không dùng được trên máy khác.

4

Kích hoạt

  1. Đóng phần mềm đang chạy (nếu đang mở).
  2. Copy file license.dat vừa nhận vào cùng thư mục với file PDF_Compare_Pro.exe.
  3. Chạy lại PDF_Compare_Pro.exe — dòng "Activation required" sẽ biến mất.
5

Cách so sánh 2 bản vẽ PDF

  1. Vào http://localhost:8000
  2. Kéo (hoặc bấm Browse chọn) file PDF bản cũ vào ô "Old Version PDF"
  3. Kéo file PDF bản mới vào ô "New Version PDF"
  4. Bấm "Find difference", đợi xử lý xong
  5. Xem kết quả qua 4 tab: Side by Side (đặt cạnh nhau) / Overlay (chồng màu) / Highlight (tô khác biệt) / Zoom chi tiết
  6. Có thể ghi chú (memo) trực tiếp lên kết quả, và xuất ra file PDF để lưu hoặc gửi đi

Một vài lưu ý

  • Phần mềm chạy hoàn toàn offline trên máy bạn — file PDF không gửi lên mạng, không rời khỏi máy.
  • license.dat chỉ dùng được trên đúng máy đã đăng ký (theo Machine ID). Đổi máy mới cần gửi lại Machine ID mới để cấp license khác.
  • Nếu Windows chặn khi mở file (SmartScreen báo "Windows protected your PC"), bấm "More info" → "Run anyway" — phần mềm chưa có chữ ký số nên đôi khi bị cảnh báo, không phải virus.
  • Có vấn đề gì trong quá trình dùng, cứ liên hệ lại phanthangjp@gmail.com, hỗ trợ trực tiếp.
